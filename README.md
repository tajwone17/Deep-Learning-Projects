# Deep Learning Projects

This repository contains university course tasks from a Deep Learning course. The notebooks cover core topics from Artificial Neural Networks (ANN) to Convolutional Neural Networks (CNN), Recurrent Neural Networks (RNN), and LSTMs.

## Course Context

- Course: Deep Learning
- Type: University practical assignment/lab tasks
- Objective: Implement and compare major deep learning architectures through guided notebook exercises

## Project Structure

1. `Task1_ANN.ipynb` - Build a basic ANN model.
2. `Task2_ANN_Hyperparameter.ipynb` - Tune ANN hyperparameters.
3. `Task3_CNN.ipynb` - Build a CNN for image-based tasks.
4. `Task4_CNN_vs_ANN.ipynb` - Compare CNN and ANN performance.
5. `Task5_CNN_Augmentation.ipynb` - Improve CNN with data augmentation.
6. `Task6_RNN_Sequence.ipynb` - Sequence modeling with RNN.
7. `Task7_RNN_Text.ipynb` - Text modeling with RNN.
8. `Task8_LSTM.ipynb` - Build and train LSTM models.
9. `Task9_LSTM_IMDb.ipynb` - Sentiment classification on IMDb with LSTM.

## Learning Path

For the best progression, run notebooks in order:

1. ANN fundamentals
2. ANN tuning
3. CNN basics
4. CNN vs ANN comparison
5. CNN augmentation
6. RNN sequence tasks
7. RNN text tasks
8. LSTM fundamentals
9. LSTM on real-world text (IMDb)

## Requirements

Install Python 3.9+ and the common ML libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn tensorflow jupyter
```

Depending on your notebook contents, you may also need:

```bash
pip install keras nltk
```

## How to Run

1. Open this folder in VS Code.
2. Open any `.ipynb` notebook.
3. Select a Python kernel/interpreter with required packages installed.
4. Run cells from top to bottom.

## Notes

- Train times may vary based on CPU/GPU availability.
- If a dataset path error appears, update the file paths inside the notebook to match your machine.
- For reproducible results, set random seeds where applicable.

## Suggested Outcomes

By completing all tasks, you should be able to:

- Build and evaluate ANN, CNN, RNN, and LSTM models.
- Apply hyperparameter tuning and data augmentation.
- Compare architectures across different problem types.
- Perform basic NLP sentiment analysis with deep learning.
